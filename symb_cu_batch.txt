# Symbol cleanup batch - resolves all 15 duplicate-address symbols
# per SYMBOL_NAMING_STANDARD.md
#
# Usage (per your README's documented workflow):
#   ./z80bench-cli batch <project_dir> < symbol_cleanup_batch.txt
#
# NOTE ON SYNTAX: `symbol add NAME ADDR CATEGORY` is confirmed from your
# README. `symbol update` is assumed to take the same argument order -
# verify that against your tool (or just run one line by hand first)
# before piping the whole file through. Same caution for `symbol remove`:
# I couldn't confirm its exact argument list from the source I had, so
# check `symbol remove` usage/help before running this for real.
#
# After running: re-run spotcheck.sh to confirm the ROM hash is unaffected.

# --- FAC / ARG (confirmed against external/TRS-80-ROMS/CONSTANTS.Z80) ---
symbol update FAC 0x7924 WRITABLE
symbol remove FAC_EXP
symbol update ARG 0x792D WRITABLE
symbol remove FAC_VAL

# --- CRUNCH (universal MS BASIC term for line tokenizing) ---
symbol update CRUNCH 0x1BF5 JUMP_LABEL
symbol remove CHK_KW

# --- PROMPT (universal MS BASIC term for the Ready-prompt routine) ---
symbol update PROMPT 0x1BB3 JUMP_LABEL
symbol remove PROMPT_RD

# --- CMD_NEW (joins existing CMD_* command-entry-point family) ---
symbol add CMD_NEW 0x1B49 JUMP_LABEL
symbol remove NEW_ENTRY
symbol remove NEW

# --- CLRSCR ---
symbol update CLRSCR 0x01C9 ROM_CALL
symbol remove CLRSCR_HOME

# --- PUSTR_* family (float-to-string output stages) ---
symbol update PUSTR_SINGLE 0x1124 JUMP_LABEL
symbol remove FFXSFX
symbol update PUSTR_NO_DECIMAL 0x113D JUMP_LABEL
symbol remove FFXSDC
symbol update PUSTR_HAS_DECIMAL 0x1157 JUMP_LABEL
symbol remove FFXSDP
symbol update PUSTR_EXP_INT 0x11A3 JUMP_LABEL
symbol remove FFXIFL
symbol update PUSTR_EXP_FLOAT 0x11AA JUMP_LABEL
symbol remove PUSTR_EXP
symbol remove FFXDFL

# --- OUT_CURSOR_ADVANCE ---
symbol update OUT_CURSOR_ADVANCE 0x31BF JUMP_LABEL
symbol remove OUT_CURSOR_INC

# --- LIST_ARGS ---
symbol update LIST_ARGS 0x1B10 JUMP_LABEL
symbol remove LSTPRM

# --- LET_VAR_PTR_LOAD ---
symbol update LET_VAR_PTR_LOAD 0x1F33 JUMP_LABEL
symbol remove LET_ENTRY_2

# --- GET_10_EXP / FONTINV (FONTINV was a stray mislabel, not a real alias) ---
symbol update GET_10_EXP 0x1201 ROM_CALL
symbol remove FONTINV
